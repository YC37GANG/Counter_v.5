# 🌿 YC37 Gang Counter — Web Dashboard

หน้าเว็บแสดงผลข้อมูลแบบเรียลไทม์จากเครื่องนับรอบ (ESP32 + Firebase) — ดูสถิติ, ประวัติ, จัดอันดับ ได้จากมือถือ/คอมพิวเตอร์ ไม่ต้องเดินไปดูที่ตัวเครื่อง

**เว็บ**: [yc37gang.github.io](https://yc37gang.github.io) _(แก้ลิงก์ตามจริง)_
**คู่กับ Firmware**: [ลิงก์ repo firmware แยกต่างหาก] _(แก้ลิงก์ตามจริง)_

---

## ✨ ฟีเจอร์

### 📊 แท็บแดชบอร์ด
- สถานะสด (live) — รอบรวม, สถานะแบต/การชาร์จของเครื่อง, Lap ที่กำลังนับอยู่
- ค้นหา/เลือกดู Lap ย้อนหลังได้จาก dropdown
- Player Grid — ดูรอบของแต่ละคนในเวลาเดียวกัน กดชื่อดูโปรไฟล์ได้
- ค่า YC ต่อ Lap (กรอกแก้ไขได้จากหน้านี้ อัปเดตขึ้นเครื่องจริงภายใน ~20 วิ)
- History Feed — ประวัติการกด +/- ทั้งหมด กรองดูรายคนได้

### 🏆 แท็บ Lap Profile
- เลือกดู Lap ไหนก็ได้แบบละเอียด
- ตารางจัดอันดับผู้เล่นในแต่ละ Lap (👑 MVP)
- เวลาเริ่ม/ปิด Lap นั้นๆ

### 📈 แท็บวิเคราะห์
- การ์ดสรุป: จำนวน Lap ทั้งหมด, รอบรวมตลอดกาล, รอบรวมของทุกคนตลอดกาล
- All-time Leaderboard พร้อมเลขจัดอันดับ
- กราฟเส้น "จำนวน Lap ต่อวัน" สไตล์กราฟหุ้น
- % ขาประจำ (attendance) ต่อคน
- คู่ที่เล่นด้วยกันบ่อยที่สุด (Top Pairs)

## 🛠️ เทคโนโลยีที่ใช้

| ส่วน | ใช้อะไร |
|---|---|
| Framework | [Alpine.js](https://alpinejs.dev/) (เบา ไม่ต้อง build) |
| ฐานข้อมูล | Firebase Realtime Database (อ่านแบบ real-time listener) |
| ฟอนต์ | Sarabun (Google Fonts) |
| Host | GitHub Pages (ฟรี ไม่ต้องมี server) |

ทั้งหมดอยู่ในไฟล์ **`index.html`** ไฟล์เดียว (HTML + CSS + JS ฝังรวมกันหมด) — เปิดได้ตรงๆ ไม่ต้อง build หรือ npm install ใดๆ

## 🚀 วิธี Deploy เอง (ถ้าจะแยกทำของตัวเอง)

### 1. ตั้งค่า Firebase config ในไฟล์
เปิด `index.html` หา section ที่ config Firebase แล้วใส่ค่าโปรเจกต์ของตัวเอง:
```js
const firebaseConfig = {
  databaseURL: "https://ชื่อโปรเจกต์คุณ.firebasedatabase.app"
};
```

### 2. ตั้งค่า Firebase Rules ให้อ่านได้แบบ Public
```json
{
  "rules": {
    ".read": true,
    ".write": false,
    "kratom_notes": { ".write": true },
    "kratom_yc": { ".write": true }
  }
}
```
> เว็บนี้เขียนได้แค่ 2 path เท่านั้น (โน้ต + YC) ส่วนข้อมูลรอบ/Lap ทั้งหมดมาจากตัวเครื่องเท่านั้น เว็บไม่มีสิทธิ์แก้ไข

### 3. เปิด GitHub Pages
- ไปที่ repo → **Settings → Pages**
- เลือก branch ที่จะ deploy (ปกติ `main`) และโฟลเดอร์ (`/root`)
- บันทึก รอสักครู่แล้วเว็บจะขึ้นที่ `https://ชื่อบัญชี.github.io/ชื่อ-repo/`

## 🔗 เกี่ยวข้องกับ Firmware

เว็บนี้เป็น**หน้าต่างดูข้อมูล**เท่านั้น ตัวข้อมูลจริงทั้งหมด (รอบ, Lap, สถานะแบต) มาจาก**เครื่องฮาร์ดแวร์ (ESP32)** ที่เขียนขึ้น Firebase โดยตรง — ดูรายละเอียดฝั่งเครื่องได้ที่ [ลิงก์ repo firmware] _(แก้ลิงก์ตามจริง)_

**field ที่เว็บแก้ไขได้จากฝั่งเว็บเอง** (ไม่ต้องพึ่งเครื่อง):
- โน้ตต่อ Lap (`/kratom_notes`)
- ค่า YC ต่อ Lap (`/kratom_yc`)

ที่เหลือ (รอบ, สร้าง/ลบ/แก้เลข Lap ฯลฯ) ต้องทำผ่านตัวเครื่องเท่านั้น

## ⚠️ ข้อจำกัดที่รู้อยู่แล้ว

- ค่า YC ที่แก้จากเว็บ **ไม่อัปเดตขึ้นเครื่องทันที** — เครื่องเช็คซ้ำทุก ~20 วินาที (ตั้งใจทำให้หน่วงเล็กน้อยเพื่อความเสถียรของเครื่อง ไม่ยิง Firebase ถี่เกินไป)
- ไม่มีระบบ login/สิทธิ์การเข้าถึง — ใครมีลิงก์เว็บก็ดูข้อมูลได้หมด (เหมาะกับกลุ่มเพื่อนที่ไว้ใจกันอยู่แล้ว)
